# Responsible AI Notes

## Key risks

- Incorrect advice
- Unsupported policy claims
- Unsafe guidance
- Privacy exposure
- Poor escalation behavior
- Overconfident responses
- Customer confusion

## Mitigations demonstrated

- Synthetic test cases
- Forbidden term checks
- Escalation expectations
- Safety-sensitive scenarios
- Human-readable failure taxonomy
- Launch criteria documentation

## Public portfolio guardrails

- Use synthetic data only
- Avoid employer-specific data, systems, metrics, roadmaps, vendor names, or policies
- Avoid claiming production readiness
- Clearly mark all assumptions and limitations
